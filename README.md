# 🎬 YOUTUBE4U - YouTube Clone

### Developed by Pranav Desai

A responsive YouTube clone website built using HTML and CSS.  
This project recreates the basic YouTube homepage layout with video thumbnails, navigation sidebar, search bar UI, and clickable YouTube videos.
